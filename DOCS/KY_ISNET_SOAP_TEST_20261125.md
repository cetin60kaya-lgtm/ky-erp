## Gerçek bağlantı kanıtı ve sonraki kapı
Kamuya açık web okumasında iki WCF servis tanıtım sayfası ve test portalı giriş sayfası döndü; web indeks tarihi yaklaşık üç ay eski. ?wsdl ve ?singleWsdl okumasında XML yerine tanıtım HTML'i döndü. Çalışma ortamı doğrudan curl: DNS çözümleme başarısız. Yetkili SOAP POST, portal oturumu ve belge gönderimi henüz yok. IP kısıtı nedeni olduğu kanıtlanmadı. Mevcut KY Control kuralları okundu, kullanıcı açık DESEN PC işlemi istemediği için PC'ye komut gönderilmedi. Yeni ücret/kurulum, Actions, merge/deploy yok.
Katalog helper + 6 sentetik sonuç durumu kontrolü; Windows PowerShell salt-okunur test scripti eklendi (bu oturumda Windows üzerinde çalıştırılmadı). Script WSDL XML ve operasyon listesi, sonra isteğe bağlı tek TEST VKN GetTaxPayer sorgusu yapar; uyumsuz proxy/şema fail-closed. Canlı veri/üretim VKN/portal şifresi yok. WSDL 1.1/Windows proxy uygunluğu gerçek ortamda doğrulanacak. Bu bir üretim SOAP transportu değildir.
Sıra: gerçek KYERP çıkışından WSDL ve sınırlı auth sorgusu → exact SOAPAction, namespace, binding ve xsd → iki test firma ile mükellef ve dört yön sayfalama → ayrı TEST verisi, sentetik tek fatura ve irsaliye, açık onay (kullanıcı bu sohbet için test izni verdi), UBL/şematron, ETTN ve nihai durum → resmi XML → İşNet'e gerçek kalıcı çıkış IP bilgisi ve başarılı belge XML'i. Cloudflare Worker'ın sabit IP'si varsayılmayacak. Gerekirse mevcut yetkili yerel/kurumsal çıkış değerlendirilecek; IP çözümü ücret/yeni altyapı gerektirirse ayrı karar. Canlıya geçiş ayrı onay.

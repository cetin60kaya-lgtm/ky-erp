# KYERP — Erken gelen müşteri irsaliyesi / XML mutabakatı
## Gerçek ihtiyaç ve kesin kurallar
Outlook'tan önce gelen PDF, manuel yükleme, File Hub ve sonradan gelen sağlayıcı XML aynı iş kaydına bağlanmalıdır. Gerçek örnek okundu; e-posta gönderen kuruluş, düzenleyici ve teslim alan farklı olabilir. Gönderen mail adresi asla belge sahibi değildir. Gerçek PDF, kişi, VKN/TCKN, ETTN, model, mail içeriği veya müşteri adı repoya taşınmaz. Sentetik test verileri kullanılır.
- Kullanıcıya tek irsaliye çalışma kaydı. Kaynak dosya olayları ayrı tutulur; mail ek kimliği ve byte hash yalnız tekrar dosyayı tanır. Tenant + düzenleyici VKN + alıcı VKN + yön + belge ailesi + ETTN; ETTN yoksa düzenleyici + alıcı + belge no + belge tarihi eşleşme adayı. Çelişki varsa inceleme, birleştirme veya yeniden faturalama yok.
- PDF ilk geldiğinde PROVISIONAL/RESMI_XML_BEKLIYOR. Dosya ve doğrulanmış kalemler korunur; PDF resmi kabul veya gönderim kanıtı değildir. Manuel kaynak numarası/ETTN ve kalem doğrulama ile işlem yapılabilmeli. Yetki ve yürürlükteki e-belge kuralları ayrı kapı. Taslak, sevk, fatura, rezervasyon kaydı değişmez kaynak iş kimliğine bağlanır.
- XML sonra gelirse aynı kaydı bul, PDF ve XML birlikte arşivle; farklı UUID/kimlik/kalem miktarında otomatik birleştirme yok. ETTN eşleşmesi tek başına XML imza/sağlayıcı veya satır doğrulaması değildir. Resmî XML kalemleri otorite; mevcut iş hareketlerini otomatik silme/değiştirme yok, çelişkiyi mutabakat kuyruğuna al.
- Miktarlar ürün/model/sipariş/renk/beden ve birim bazında; taslak rezervasyonu, gönderim belirsizliği, resmî sevk, resmî fatura ve iptal ayrı. D1 atomik claim, idempotency key, satır bazlı rezervasyon ve provider sonuç sorgusu; ikinci kesim bloke. Doğrudan İşNet'te elle kesilen belgeler XML ile geldiğinde kaynak referansı/kayıtlı ilişkilerden eşleştir; birden fazla aday veya belirsiz miktarda insan kontrolü, tahmini bağlantı yok.
- Mevcut Mail & Dosyalar ve File Hub tek kaynak. Tenant ve posta hesabı üyeliği zorunlu, firma sahibi onaylı bağlayıcı. Graph delta/checkpoint, sayfalama, attachment dedup, eksik/tarafı belirsiz ek kuyruğu, geri tarama ve tekrar erişim. Cursor ancak dosyalar kalıcı kuyruğa girince ilerler; ileri tarih/senkron arızası ayrı gösterilir. Silme, mail gönderme yok.
- Cari kartları otomatik değiştirilmez. Doğrulanmış satış/alış XML geçmişi ile müşteri/tedarikçi önerisi; ikili/çelişkili durum ayrı inceleme. İade ve iptal hariç. Belirsiz cari genel bakıştan kaybolmaz.
## Bu paket
1. Azure OCR etiketli ETTN çıkarımı; farklı ETTN'ler belirsiz.
2. Saf erken kaynak kimlik karşılaştırıcı ve sentetik testleri (henüz write/merge yoluna bağlanmadı).
3. Mevcut müşteri takip API'sine tenant/VKN/verified UBL satış-alış kanıtı, explicit cari kartını değiştirmeden sınıflandırma ve cari kontrol kısayolu. Tahmini müşteri için resmi işlem kısayolu kapalı; kart doğrulaması gerekir.
## Açık ve zorunlu
Mevcut findDuplicate/attachDuplicateFile akışı ETTN/no eşleştirip yalnız dosya ekleyebiliyor; satır/çakışma/atomik mutabakat ve kalıcı erken kaynak rezervasyonu henüz yok. Eski PDF kayıtları resmi scope varsayılanıyla oluşturuluyor; geriye dönük veri değişikliği yapılmadı. Outlook delta/senkron runtime, gelen PDF provisional kayıt, manuel kaynak UI, claim/rezervasyon, XML yükseltme, İşNet dışarıdan kesilmiş belge mutabakatı, geçmiş tamamlık kontrolü ve canlı kabul tamamlanmadan mükerrer koruma tamamlandı denemez. D1 migration için açık onay + yedek + readiness. Bu paket üretime uygulanmadı; gerçek belge gönderilmedi.

# KY ERP Frontend

Bu paket, KY ERP uygulamasinin React + Vite tabanli on yuzudur.

## Komutlar

```powershell
npm install
npm run dev -- --host
npm run build
```

## Gelistirme Notlari

- Bu klasor tek basina monorepo kok degildir; backend ile birlikte calisir.
- Tam kurulum ve veritabani baslatma akisi icin kokteki README.md dosyasini kullanin.
- Uretim veya smoke dogrulamasi yapmadan once backend servisinin ayakta oldugundan emin olun.

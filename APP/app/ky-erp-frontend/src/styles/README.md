# KY ERP Shell V3

Bu klasördeki `shell-v3.css`, çalışan `App.jsx` route, yetki, aktif firma, hata sınırı ve modül yükleme mantığını değiştirmeden yalnız masaüstü/tablet uygulama kabuğunu düzenler.

Kapsam:
- koyu dar ana modül rayı,
- beyaz ikinci seviye modül menüsü,
- ortak üst bar,
- aktif firma ve kullanıcı alanı,
- kontrollü içerik kaydırma,
- tablet ve mobil menü davranışı.

Bu stil, `main.jsx` içinde `App.css` sonrasında yüklenir. Modül içi iş kurallarını veya API davranışını değiştirmez.
